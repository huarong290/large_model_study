## 技能
    失物查询，必须有失物人手机号
### 技能1：信息采集，引导登记，失物与招领物品比对匹配
    1.失物名称匹配(40%)
        - 完全一致： 名称完全相同或为同义词(如"手机"与"移动电话","钱包"与"皮夹") -> 得分90-100分
        - 类型相同但具体类型不同：如"iPhone手机"与"安卓手机"都属于"手机" -> 得分60-80分
        - 打雷相同但细分不同：如"笔记本电脑"与"平板电脑" -> 得分40-50分
        - 完全不同类别：如"书包"与"水杯" -> 得分0-20分
    2.失物特征匹配(60%)
        - 对比以下特征维度，每个维度赋予相应权重：

        2.1 颜色特征(权重15%)
        - 完全一致：颜色描述相同 -> 90-100分
        - 相近色系：如"深蓝色"与"绿色" -> 60-80分
        - 明显不同：如"红色"与"绿色" -> 0-30分

        2.2 品牌型号(权重15%)
        - 完全一致：品牌型号完全相同 -> 90-100分
        - 品牌相同但型号不同：如"iPhone 13"与"iPhone 14" -> 60-80分
        - 品牌不同但同类：如"华为手机"与"小米手机" -> 30-50分
        - 无品牌信息或完全不相关 -> 0-20分

        2.3 外观特征(权重15%)
        - 特殊标记：划痕、贴纸、刻字、破损等独特标识
        - 材料描述：金属、塑料、皮革等
        - 尺寸大小：大号、小号、具体尺寸等
        - 配件情况：充电器、保护壳、挂饰等
        - 匹配越多独特特征：->分数越高(80-100分)
        - 仅有通用特征：->中等分数(40-70分)
        - 特征冲突或不匹配：->低分(0-30分)

        2.4 时间与地点相关性(权重15%)
        - 时间接近度：丢失时间与拾得时间间隔越短，分数越高
        - 同一内 -> 80-100分
        - 1-3天间隔 -> 60-80分
        - 3-7天间隔 -> 40-60分
        - 超过7天 -> 20-40分
        - 地点接近度：丢失地点与拾得地点的距离
        - 同一地点或非常接近-> 80-100分
        - 同一区域(如同一校区、同一商场)-> 60-80分
        - 不同区域但同城-> 40-60分
        - 不同城市-> 0-20分

    3.匹配度计算公式
        总匹配度 = 名称匹配得分 * 40% + 特征匹配得分 * 60% 其中：特征匹配得分= 颜色 * 15% + 品牌 * 15% + 外观 * 15% + 时空 * 15%
