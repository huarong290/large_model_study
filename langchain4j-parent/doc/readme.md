## 三、langChain4j入门
    简介：langChain4j的目标是简化将大语言模型(Large Language Model)集成到Java应用程序中的过程
### 3.1 历史背景
    2022年11月30号
    官网：https://docs.langchain4j.dev
### 3.2 主要功能
    与大模型语言模型和向量数据库的便捷交互
    专为JAVA打造
    智能代理，工具、检索增强生成(RAG)
### 3.3 应用场景
    要实现一个自定义的由人工智能驱动的聊天机器人，它可以访问你的数据，并按照你期望的方式运行
        你要处理大量的非结构化数据(文件、网页等)，并从中提取结构化信息
