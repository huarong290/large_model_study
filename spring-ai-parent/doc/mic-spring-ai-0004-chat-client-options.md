│  3. 理解 TopP（核采样）的作用                                       │
│  4. 理解 FrequencyPenalty 和 PresencePenalty                        │
│  5. 掌握不同场景下的参数调优策略                                    │
│  6. 对比不同参数配置的响应效果                                      │
│                                                                     │
│  核心概念：                                                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  参数        │ 范围      │ 作用                            │    │
│  ├──────────────┼───────────┼─────────────────────────────────┤    │
│  │ Temperature  │ 0.0 - 2.0 │ 控制回答的随机性和创造性       │    │
│  │ MaxTokens    │ 1 - 4096  │ 限制输出内容的最大长度          │    │
│  │ TopP         │ 0.0 - 1.0 │ 核采样，控制词汇多样性          │    │
│  │ FrequencyPen │ -2.0-2.0  │ 降低重复词汇的频率              │    │
│  │ PresencePen  │ -2.0-2.0  │ 鼓励引入新词汇                  │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

# ================================================================
# 1. 预设模式测试
# ================================================================

# 创意模式（高温度）
curl "http://localhost:12104/api/options/preset?mode=creative&message=写一首关于春天的诗"

# 精准模式（低温度）
curl "http://localhost:12104/api/options/preset?mode=precise&message=1+1等于多少"

# 简洁模式（短输出）
curl "http://localhost:12104/api/options/preset?mode=concise&message=介绍人工智能"

# 详细模式（长输出）
curl "http://localhost:12104/api/options/preset?mode=verbose&message=介绍人工智能"

# 平衡模式（默认）
curl "http://localhost:12104/api/options/preset?mode=balanced&message=你好"

# ================================================================
# 2. 自定义参数测试
# ================================================================

# 低温度 + 短输出
curl "http://localhost:12104/api/options/custom?message=1+1等于多少&temperature=0.1&maxTokens=50"

# 高温度 + 长输出
curl "http://localhost:12104/api/options/custom?message=写一首关于春天的诗&temperature=1.5&maxTokens=2048"
