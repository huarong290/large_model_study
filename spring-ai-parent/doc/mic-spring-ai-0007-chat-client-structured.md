
┌─────────────────────────────────────────────────────────────────────┐
│              mic-spring-ai-0007-chat-client-structured             │
│                        结构化输出                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  学习目标：                                                         │
│  1. 理解结构化输出的作用和优势                                     │
│  2. 掌握映射到 Java Bean 的方法                                     │
│  3. 掌握映射到 Record 的方法                                        │
│  4. 掌握映射到 List/Map 的方法                                     │
│  5. 掌握处理嵌套对象的方法                                          │
│  6. 掌握自定义 JSON Schema                                          │
│  7. 实现复杂对象的反序列化                                          │
│                                                                     │
│  核心概念：                                                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  输出类型    │ 方法                    │ 适用场景           │    │
│  ├──────────────┼─────────────────────────┼────────────────────┤    │
│  │  Java Bean   │ .entity(MyClass.class)  │ 固定结构的对象     │    │
│  │  Record      │ .entity(MyRecord.class) │ 不可变数据对象     │    │
│  │  List        │ .entity(List.class)     │ 列表数据           │    │
│  │  Map         │ .entity(Map.class)      │ 动态键值对         │    │
│  │  嵌套对象    │ .entity(Parent.class)   │ 复杂层级结构       │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  优势：                                                             │
│  1. 类型安全 - 编译时检查                                          │
│  2. 自动解析 - 无需手动处理 JSON                                    │
│  3. 易于使用 - 直接操作 Java 对象                                  │
│  4. 代码清晰 - 减少样板代码                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

# ================================================================
# 1. Java Bean
# ================================================================

# 用户信息
curl "http://localhost:12107/api/structured/user?name=张三&city=北京"

# 国家信息
curl "http://localhost:12107/api/structured/country?name=中国"

# ================================================================
# 2. Record
# ================================================================

# 人物信息
curl "http://localhost:12107/api/structured/person?name=李四"

# ================================================================
# 3. List
# ================================================================

# 城市列表
curl "http://localhost:12107/api/structured/cities"

# 名人列表
curl "http://localhost:12107/api/structured/famous-people"

# ================================================================
# 4. 嵌套对象
# ================================================================

# 演员电影
curl "http://localhost:12107/api/structured/actor?name=梁朝伟"

# ================================================================
# 5. 复杂对象
# ================================================================

# 菜谱
curl "http://localhost:12107/api/structured/recipe?name=宫保鸡丁"

# ================================================================
# 6. 批量处理
# ================================================================

# 多个国家
curl "http://localhost:12107/api/structured/countries?names=中国,日本,韩国"

# ================================================================
# 7. 对比
# ================================================================

curl "http://localhost:12107/api/structured/compare?name=张三"
