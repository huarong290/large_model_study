│  核心概念：                                                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  Advisor 是什么？                                            │    │
│  │  Advisor = 拦截器 = 在 AI 调用前后插入自定义逻辑             │    │
│  │                                                             │    │
│  │  执行流程：                                                 │    │
│  │  用户请求 → Advisor.before() → AI 调用 → Advisor.after() → 返回 │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  内置 Advisor：                                                     │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  1. MessageChatMemoryAdvisor  - 对话记忆                    │    │
│  │  2. SimpleLoggerAdvisor       - 日志记录                    │    │
│  │  3. QuestionAnswerAdvisor     - RAG 检索                    │    │
│  │  4. ToolCallAdvisor           - 工具调用                    │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  自定义 Advisor：                                                   │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  1. 日志记录 Advisor  - 记录请求/响应                       │    │
│  │  2. 性能监控 Advisor  - 记录耗时                           │    │
│  │  3. 缓存 Advisor      - 缓存响应                          │    │
│  │  4. 审计 Advisor      - 记录用户操作                      │    │
│  │  5. 限流 Advisor      - 控制请求频率                      │    │
│  │  6. 敏感词 Advisor    - 过滤敏感词                        │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

# ================================================================
# 1. 带所有 Advisor 的对话
# ================================================================

curl -X POST "http://localhost:12111/api/advisor/chat" \
-H "Content-Type: application/json" \
-d '{"message": "你好，请介绍一下自己"}'

# ================================================================
# 2. 带指定 Advisor 的对话
# ================================================================

# 只有日志和性能监控
curl -X POST "http://localhost:12111/api/advisor/chat/select?advisors=logging,performance" \
-H "Content-Type: application/json" \
-d '{"message": "你好"}'

# 只有审计日志
curl -X POST "http://localhost:12111/api/advisor/chat/select?advisors=audit" \
-H "Content-Type: application/json" \
-d '{"message": "介绍一下 Spring AI"}'

# 只有限流
curl -X POST "http://localhost:12111/api/advisor/chat/select?advisors=ratelimit" \
-H "Content-Type: application/json" \
-d '{"message": "你好"}'

# ================================================================
# 3. 无 Advisor 的对话（对比）
# ================================================================

curl -X POST "http://localhost:12111/api/advisor/chat/no-advisor" \
-H "Content-Type: application/json" \
-d '{"message": "你好"}'

# ================================================================
# 4. 获取统计信息
# ================================================================

curl "http://localhost:12111/api/advisor/stats"

# ================================================================
# 5. 清除缓存
# ================================================================

curl -X DELETE "http://localhost:12111/api/advisor/cache"
