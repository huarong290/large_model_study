# ================================================================
# 1. 基础健康检查 (Actuator 监控端点)
# ================================================================

# 查看服务健康状态（确认 Actuator 正常）
curl "http://localhost:12112/actuator/health"

# 查看 Trace 链路统计端点（如果开启了 metrics）
curl "http://localhost:12112/actuator/metrics"

# ================================================================
# 2. 带 Advisor 链的对话请求（可观测性入口）
# ================================================================

# 核心请求：会触发 Logging、Audit、Cache、RateLimit、Performance 等 Advisor
# 每行控制台日志均携带 TraceId: [6a70b90d43d6588...]
curl -X POST "http://localhost:12112/api/advisor/chat" \
-H "Content-Type: application/json" \
-d '{"message": "你好，请介绍一下自己"}'

# ================================================================
# 3. 结合可观测性的特色测试
# ================================================================

# 触发缓存命中（请求同样的内容，查看 PerformanceAdvisor 耗时变化）
curl -X POST "http://localhost:12112/api/advisor/chat" \
-H "Content-Type: application/json" \
-d '{"message": "你好，请介绍一下自己"}'

# ================================================================
# 4. 获取实时统计信息（由 PerformanceAdvisor 提供）
# ================================================================

# 查看总调用次数、平均耗时、最小/最大耗时等数据
curl "http://localhost:12112/api/advisor/stats"

# ================================================================
# 5. 清除本地缓存（由 CacheAdvisor 提供）
# ================================================================

curl -X DELETE "http://localhost:12112/api/advisor/cache"

# ================================================================
# 6. Zipkin 链路可视化查看（最终成果！）
# ================================================================

# 在控制台日志中找出一行带有 TraceId 的记录，例如：
# [6a70b90d43d6588cc9da20c53f6a5370] ...

# 打开链路追踪 UI（如果你使用了本地 Docker Zipkin）：
open http://localhost:9411

# 或者如果你还在用之前的在线 Demo（虽然大概率已失效）：
# https://zipkin-query.demo.elastic.cloud/zipkin/

# 将上面那串 TraceId 粘贴到 UI 搜索框中，即可查看本次 AI 调用的耗时瀑布图！
