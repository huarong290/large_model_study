│                         多模型智能路由                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  核心概念：                                                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  多模型路由（Multi-Model Routing）是什么？                   │    │
│  │  通过策略自动选择最适合当前任务的 AI 模型，平衡成本与效果。   │    │
│  │                                                             │    │
│  │  执行流程：                                                 │    │
│  │  用户提问 → 模型路由策略判断 → 路由至选定模型 → 返回响应    │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  模型注册表：                                                       │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  模型名称    │ 类型     │ 能力特点                         │    │
│  ├──────────────┼──────────┼──────────────────────────────────┤    │
│  │  Ollama      │ 本地     │ 免费、快速、隐私安全、适合简单对话│    │
│  │  DeepSeek    │ 云端     │ 强大逻辑、代码能力强、适合复杂任务│    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  路由策略（当前为基于关键词的硬编码路由）：                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  触发关键词：写个、代码、实现、分析、翻译、算法              │    │
│  │  命中关键词 → 自动路由至 DeepSeek（云端，处理复杂逻辑）      │    │
│  │  未命中关键词 → 自动路由至 Ollama（本地，快速响应）          │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  架构亮点：                                                         │
│  1. 接口与实现分离：ModelRouterService + ModelRouterServiceImpl    │
│  2. 多 Bean 管理：通过 @Qualifier 区分注入 ChatClient              │
│  3. 模型注册表：便于后续扩展第三方模型                             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

# 2. 多模型路由测试（POST）
# ================================================================

# 【测试一：普通对话】
# 不含关键词，预期路由至：Ollama 本地模型（响应速度快）
curl -X POST "http://localhost:12113/api/router/chat" \
-H "Content-Type: application/json" \
-d '{"message": "你好，请介绍一下你自己"}'

# 【测试二：技术复杂逻辑】
# 包含关键词“代码”，预期路由至：DeepSeek 云端模型（逻辑能力更强）
curl -X POST "http://localhost:12113/api/router/chat" \
-H "Content-Type: application/json" \
-d '{"message": "请帮我用 Java 写一个冒泡排序算法，并加中文注释"}'

# 【测试三：深度分析请求】
# 包含关键词“分析”，预期路由至：DeepSeek 云端模型
curl -X POST "http://localhost:12113/api/router/chat" \
-H "Content-Type: application/json" \
-d '{"message": "分析一下 Spring AI 中多模型路由的设计优缺点"}'

# 【测试四：翻译任务】
# 包含关键词“翻译”，预期路由至：DeepSeek 云端模型
curl -X POST "http://localhost:12113/api/router/chat" \
-H "Content-Type: application/json" \
-d '{"message": "翻译一下这句话：Artificial Intelligence is transforming the world."}'

# 【测试五：常识/知识问答】
# 不含关键词，预期路由至：Ollama 本地模型
curl -X POST "http://localhost:12113/api/router/chat" \
-H "Content-Type: application/json" \
-d '{"message": "你知道珠穆朗玛峰有多高吗？"}'
