│  核心问题：                                                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  如何评估 AI 回答的质量？                                    │    │
│  │  1. 准确性 - 回答是否正确                                   │    │
│  │  2. 完整性 - 回答是否全面                                   │    │
│  │  3. 相关性 - 回答是否切题                                   │    │
│  │  4. 流畅性 - 回答是否自然                                   │    │
│  │  5. 有用性 - 回答是否解决问题                               │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  评估方法：                                                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  1. 自动评分  - 使用 AI 对回答进行打分                      │    │
│  │  2. 对比测试  - 对比不同模型的回答质量                      │    │
│  │  3. A/B测试   - 对比不同参数配置的效果                      │    │
│  │  4. 人工评估  - 提供人工评分接口                           │    │
│  │  5. 指标统计  - 统计 Token 使用、响应时间等                 │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
# ================================================================
# 1. 自动评分
# ================================================================

curl -X POST "http://localhost:12116/api/evaluation/score" \
-H "Content-Type: application/json" \
-d '{
"question": "什么是人工智能？",
"answer": "人工智能是计算机科学的一个分支，致力于创建能够执行通常需要人类智能的任务的系统。"
}'

# ================================================================
# 2. 模型对比
# ================================================================

curl -X POST "http://localhost:12116/api/evaluation/compare" \
-H "Content-Type: application/json" \
-d '{"question": "什么是Spring AI？"}'

# ================================================================
# 3. A/B 测试
# ================================================================

curl -X POST "http://localhost:12116/api/evaluation/ab-test" \
-H "Content-Type: application/json" \
-d '{"question": "写一首关于春天的诗"}'

# ================================================================
# 4. 统计信息
# ================================================================

curl "http://localhost:12116/api/evaluation/stats"
